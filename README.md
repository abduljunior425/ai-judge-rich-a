Entry for [Make the AI judge rich](https://make.fun/bounty/ai-judge-rich-01) on
[make.fun](https://make.fun): a program (`main.ts`, Node 22, stdlib only) that
writes one short plan to `/output/entry.txt` — the plan an AI agent would
follow to turn $100 into the most money in 30 days, with no human doing the
work.

The plan, "The Builder's Compound": sell done-for-you micro-automations to
small businesses, reinvest every dollar into compute and API, and scale with
parallel agents — concrete day-by-day allocation of the $100, exact price
points, strict risk caps, a daily reinvestment loop, and measurable
milestones. No randomness, no network, no timestamps: both runs write
byte-identical output.
